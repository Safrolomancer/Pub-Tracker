## Overview

**Pub Tracker** is a Kotlin-based console application designed to manage pubs, users, and visit activity.

The project is being developed incrementally using modern software development practices, including:

- layered architecture
- issue-based GitHub workflow
- Gradle build automation
- JUnit testing
- versioned releases

---

## Architecture

The project follows a **layered architecture**:

- **Model** — data entities
- **Repository** — storage and data access
- **Service** — business logic and validation
- **UI** — console interaction

This keeps the project maintainable, testable, and easy to extend.
